## 项目现状（30 秒版）

单文件桌面游戏（Python 只做宿主，全部物理/AGC/渲染/UI 在 12 个按前缀排序的 JS

（含天平动）+ 通用变量二体传播 + 兰伯特 + RK4 自适应步长（地球 μ+J2、月球 μ+J2、

## 重构目标（用户指定的三个方向）

### A. 真实科学性的轨道学

当前是"够用的教学级保真"。升级为更真实的轨道学，优先级从高到低：

1. **有限推力点火代替瞬时脉冲**：现在 `World.impulsiveBurn` 是瞬时 Δv，而真实
   TLI 燃烧 347 s、LOI 燃烧 ~6 min。把点火改为有限燃烧模型（姿态保持 + 推进剂
   实时消耗 + 重力损耗），并保持/贴近 03 文档基准表里的 Δv 数值。
2. **历表与坐标系**：Meeus 截断级数可升阶；月球轨道相对赤道的倾角目前固定
   28.58°，应建模交点退行（18.6 年周期的短周期近似即可）。
3. **大气**：分段指数模型 → US Standard 1976 式分层或 NRLMSISE 简化版，
   可加简单风场。发射段方位角与俯仰程序需要重新标定（当前 69.4° vs 实飞 72.03°）。
4. **月球低阶重力场**（可选）：月海质量瘤对低环月轨道的摄动。
5. **积分器**（可选）：RK4 → 带误差控制的 RKF45/DP853；**必须保留**
   "每帧 ≤1400 步 + 高度自适应步长（月面 0.02 s ↔ 深空 60 s）"的实时性约束。

### B. 动力学

1. **制导律与真实 Apollo 对齐（最重要）**：现有 `descentGuidance` 是
   自研三段式（P63 制动 → 接近 → P66 终端），制动段用 `tgo = 2s/vh` 的
   自杀式制动。**必须改成射程-速度调度的 Apollo 剖面**，并修掉 03 文档 5.1 节
   描述的 M5 着陆失败（10 km 悬停烧干 → 227 m/s 砸月面）。M4（37 m 落点）
   是回归下限：重构后 M4、M5 都要 landed 且落点 ≤ 40 m。
2. **姿态/RCS 动力学**：目前姿态是理想化瞬时指向。加简化 RCS（平移小推力 +
   姿态跟踪带宽），至少让"姿态模式切换"有物理过渡而不是瞬变。
3. **着陆/对接判定**：软着陆标准（垂直 < 3 m/s、水平 < 1 m/s、姿态角限制）；
   对接的相对速度/对准角约束（现在 < 150 m + < 20 m/s 太宽）。
4. **分级/分离事件**：分级抛离物作为独立 Craft 继续存在（当前已有 jettisonModule），
   保留"不偷跨级推进剂"的约束（见 01 文档 6.10）。

### C. 教程部分 —— 制导面板的操作说明（用户明确要求，缺得最严重）

**现状**：教程两套课程讲了遥测、视图、姿态模式、计算器、DSKY、任务打法，
**但没有成体系的"制导面板"操作说明**；制导逻辑本身（每条制导律什么时候该用、
和真实 Apollo 程序号的对应）在 UI 里完全没有地方可读。

**要求**：
1. **单独新增一个区域或按钮**（建议：底部第 7 个页签「制导手册」，并在教程里
   留跳转入口），内容分两部分：
   a. **整个制导逻辑**：逐条讲清本模拟器里的每一条制导律 —— 上升制导
      （俯仰程序 + 关机条件）、入轨 VGO、动力下降 P63/P64/P66、交会制导、
      月面起飞、环月平面设置、TEI —— 各自的**原理、适用阶段、输入输出、
      在哪个面板上怎么触发**，以及与真实 Apollo 程序号（P11/P40/P63/P64/P66/
      P30/P42…）的对应关系；
   b. **整个面板的使用说明**：飞行控制条（7 种姿态模式各自何时用、油门/关机/
      全推力、自动驾驶、分级、分离/对接）、轨道计算器（两个输入、输出怎么读、
      4+1 个动作按钮分别在什么轨道状态下点）、时间倍率（含自动演示的接管与
      限幅规则）、AGC 接口通道 `030o 油门 / 031o 姿态 / 032o 分级` 的用法与
      示例程序思路。
   每个控件都回答三件事：**什么时候用 / 点了会发生什么 / 一个典型操作序列**。
2. 教程课程里补一节「制导面板实操」（交互式，可复用现有 target/wait 机制），
   并保持**绝不自动播放**的铁律（01 文档第 3 节）。
3. 全部内容双语：新词条 `DICT.zh/DICT.en` **两边一起加**，画布/按钮文字走
   `APL.t()`（01 文档第 2 节的全部规则）。
4. **文档必须与代码行为一致**：手册里每个"典型操作序列"都要用无头探针真的
   跑一遍（见 02 文档第 4 节的探针生成器套路），确认按文档操作能得到文档
   描述的结果。

## 铁律（完整版在 01 文档，这里是摘要 —— 违反任何一条即返工）

1. Python 只做宿主；所有逻辑在 JS；文件按 `00-`~`11-` 前缀顺序加载；新增资源
   同步进 `tools/build_exe.py` 的 `--add-data`。
2. i18n 词条两边一起加；切语言重建所有运行时内容；不在 bootstrap 里硬编码
   覆盖 data-i18n 按钮；画布文字走 `APL.t()`。
3. 任何自动弹出/自动播放/自动开始的引导一律禁止。
4. 演示接口必须真导出（不许 `a && a.b()` 式静默失败）；步骤切换当帧刷新控制量；
   倍率共享状态走 `setWarpValue`；异常中止必须显式报出来。
5. 相机状态（`cam.customBasis`）跨模式必须每帧清；`ctx.arc` 半径先夹再算
   （负半径会打死整个渲染主循环）。
6. 改物理参数前先对照 03 文档第 3 节基准表；改完不允许劣化。
7. `impulsiveBurn` 不许跨级偷登月舱推进剂。
