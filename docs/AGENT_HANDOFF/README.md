## 项目一句话

一个单文件 Windows 桌面小游戏：模拟阿波罗 11 号从点火起飞 → 地月转移 → 环月 →
动力下降着陆 → 月面起飞 → 交会对接 → 返回溅落（195 h 18 min）的**全过程**，
全部轨道计算基于真实飞行数据与 Meeus 月球历表，并内置一台可编程的 AGC 复刻
（可自己写 AGC 汇编驱动 DSKY）。

- 交付物：`dist/Apollo11LunarLanding.exe`（PyInstaller 单文件，双击即玩）
- 技术栈：Python 只做宿主（pywebview 窗口 + 文件桥），**所有物理 / AGC / 渲染 / UI 全在 JavaScript 里**
- 参考仓库（只复刻功能，禁止抄代码）：`chrislgarry/apollo-11`、`virtualagc/virtualagc`

## 最快上手（新 Agent 的第一小时）

```bash
# 1) 从源码跑起来（需要带 pywebview 的 Python，本机用 binaries/python/envs/default）
python run.py

# 2) 跑一次资源自检（不弹窗口）
APOLLO11_HEADLESS=1 python run.py

# 3) 跑全面 bug 扫描（无头 Edge，详见 02-工具链.md）
node tools/make_bughunt_probe.js .
msedge --headless=new ... --dump-dom ".../apollo11/webdata/_bughunt_probe.html"

# 4) 重新打包 exe
python tools/build_exe.py
```

改任何代码后的**最低验收标准**：语法检查全过 → 页面自检 11/11 →
`tools/bughunt.js` 0 异常 → M4 自动演示仍 `landed=true`（落点偏差 ~37 m）→
重新打包 exe 并自检 PASS。详见 `02-工具链.md` 的"验收清单"一节。
