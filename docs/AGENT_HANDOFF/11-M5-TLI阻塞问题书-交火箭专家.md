## 0. 三十秒摘要

我们复刻阿波罗 11 号全流程（发射→地月转移→环月→着陆→月面上升→交会→返回）。
**M1~M4 已达标，M5（全流程）卡在"地月转移点火（TLI）"**：

- 从**真实上升段**飞出的停泊轨道 184.4 × 185.2 km、i=32.55°（与真实 183.2×185.9、32.521° 基本一致）；
- TLI 时 S-IVB 剩推进剂 **76.24 t**，全堆 **142.7 t**，Isp 424 s、真空推力 1.0 MN
  → 可交付 **3179 m/s**；
- 但**我们的瞄准求解要求 3288 m/s**（最省的合格窗口）→ **差 109 m/s**。
- 参考：真实阿波罗 11 号 TLI 是 **3050 m/s / 燃烧 347 s**（从 183.2×185.9 km 出发）。

**最可疑的一点（请重点判断）**：真实任务的转移飞行是 **75.9 h**；
而我们在**同一发射时刻**（T+10069 s 点火，真实 T+9861 s，差 3.5 min）
用全模型求解得到的**最优飞行时间是 96~100 h**。名单里根本没有 75.9 h 的窗口能过验收。
如果历表与轨道面都对，真实那条 75.9 h 的转移从我们的停泊轨道出发**应该在最优附近**。
20 小时量级的偏差，通常说明历表、月球位置、轨道面或出发能量里有一处不对。

## 1. 模拟器的相关构造（判断前需要知道的边界）

| 项 | 取值/做法 |
|---|---|
| 时间尺度 | 世界时间 = 真实历元（发射 1969-07-16 13:32 UT，JD 2440419.0639）。月球位置用 Meeus 级数 + 地球 J2 + 太阳摄动，月球自转用 IAU 2000（含天平动） |
| 引力 | 地心系：地球点质量 + J2；月球：点质量 **+ 间接项** `−μ_m·r_m/|r_m|³`（已修）+ 月球 J2（用 `p = r − r_m`）；太阳：点质量 + 间接项；月球 SOI 切换 |
| 积分 | RK4，步长表按高度（近地 0.5~1 s、地月转移 30~90 s）。规划与实飞同源（本轮专门修过：点火段用引擎自然步长驱动） |
| 地月转移规划 | 广义兰伯特（多圈）+ **两阶段有限动力弧打靶**（姿态偏置 a,b + 燃烧时长 T 的 2 参数牛顿），目标函数只有三项：**近月点高度 − 111 km**、**到达轨道面与着陆点方向夹角**、**到达 v∞ − 目标 v∞** |
| 验收（硬闸门） | 近月点 111 ± 20 km；到达面夹角 ≤ 0.1°（到达面必须含月面着陆点 0.674°N / 23.473°E 的方向）；v∞ ∈ [0.83, 0.90] km/s；解析修正 ≤ 20 m/s |
| TLI 的 Δv 定义 | 报告的是**冲量等效 Δv**（把有限弧所需的等效冲量折算回瞬时脉冲），用于与推进剂预算比较 |

## 2. 阻塞点的精确数字（全部实测）

### 2.1 出发端（TLI 时刻）

- 点火时刻 T+10069 s（**真实 T+9861 s**，差 3.5 min）。
- 停泊轨道：**184.376 × 185.232 km**，i = **32.552°**（真实 183.2 × 185.9 km，i = 32.521°）。
- S-IVB 推进剂**剩余 76.24 t**；全堆质量 **142.7 t**（S-IVB 干重 15.2 t + 有效载荷组合 ~51 t）。
- S-IVB 真空推力 1.0 MN、Isp 424 s → 理想可用 Δv = 4.159 × ln(142.7 / 66.46) = **3179 m/s**。

### 2.2 到达端（我们求解出的最优窗口）

| 项 | 数值 |
|---|---|
| 飞行时间（最优窗口） | **96~100 h**（真实 **75.9 h**） |
| 到达近月点 | 109~116 km ✓ |
| 到达面夹角 | ≤ 0.1° ✓ |
| 到达 v∞ | 0.846~0.857 ✓ |
| **需要 Δv** | **3259 m/s（规划态）/ 3288 m/s（真实状态重解）** |
| 两体兰伯特在该几何下的下限 | **3150~3160 m/s** |

### 2.3 差距分解（我们的推断，请专家校验）

- 两体下限 ≈ 3150（**比真实任务的 3050 高 ~100 m/s**，若历表/几何无误应更接近）；
- 到达面约束（"到达面必须含着陆点"）在最优窗口上再加 **+100~140 m/s**；
- 规划态与实飞态的滑行差异再 +29 m/s；
- 合计 ≈ 3288，而可用 3179 → **差 109 m/s**。

### 2.4 目击到的两个"耦合"（有可能是根因线索）

1. **"面天然对"的窗口 v∞ 偏低**：扫描里到达面夹角只有 **0.011°~0.03°** 的窗口
   （即到达面几乎正好含着陆点），其 v∞ 只有 **0.817~0.820**，
   低于我们采用的 0.83 下限 → 被淘汰。而 v∞ 达标的窗口，面夹角都在 0.1~0.3°。
   **是否说明"面与 v∞ 在本历元几何下天然耦合"？还是我们的搜索/建模有偏？**
2. **TOF 与真实差 20 h**（见 §0）。真实 75.9 h 的窗口在我们这里过不了验收
   （旧的搜索曾用过 64~80 h 的 TOF 区间，后来因"到不了近月点/能量不对"被移出名单，
   现用 88~104 h）。**请判断这是正常的（本模型历元/几何与真实不同）还是不正常的。**

## 2.5 ★ 后补的关键数据：真实 75.9 h 转移在我们模型里的表现（2026-10-15 加）

我们把点火时刻的真实停泊状态导出，用两体兰伯特**逐个飞行时间**求解（瞄月心），
得到（完整数据见 `outputs/tli-pack/tli-pack.txt`）：

| TOF(h) | Δv(m/s) | 到达 v∞(km/s) | 备注 |
|---|---|---|---|
| **75.9（真实）** | **3180** | **1.0874** | 与真实任务同量级 |
| 80 | 3161 | 1.0312 | |
| 84 | 3147 | 0.9856 | 本表最省 |
| 88 | 3151 | 0.9483 | |
| 96 | 5180 | 0.9061 | 几何恶劣（兰伯特近奇异）|
| 100 | 3577 | 0.8734 | |
| 104 | 3417 | 0.8576 | |

出发状态（点火时刻 t=10069.5 s，真实历元）：
- 停泊轨道 a=6568.647 km（高度当量 190.5，**瞬时点**）、e=1.217e-3、i=**32.5915°**、RAAN=**358.820°**、argp=345.937°；
- r0=[6534.820, 451.849, 374.849] km、v0=[−0.689203, 6.549541, 4.177279] km/s（ECI）；
- 全堆 142 667 kg；S-IVB 推进剂剩 76 241 kg；
- 月球 @t0：r=[−293839.957, 244906.637, 129020.041]、|r|=403 692 km、|v|=0.9768 km/s（**接近远地点**）；
- **停泊轨道面 ↔ 月球轨道面夹角 = 4.114°**；月球轨道面与赤道夹角 28.479°。

### 由此得到的新判断（供专家裁决）

1. **真实任务的到达 v∞ 应该是 ≈1.09，而不是我们采用的 0.83~0.90。**
   验算：v∞=1.087、近月点 111 km 的双曲线近月点速度
   `√(1.087² + 2μ_m/1848.4) = 2.547 km/s`，目标 111×315 km 椭圆在近月点的速度
   `√(μ_m(2/1848.4 − 1/1950.4)) = 1.671 km/s` → **LOI-1 = 876 m/s**
   （真实任务 889 m/s，差 1.5%）。即：只有 v∞≈1.09 才能复现真实的 LOI-1。
   我们的 0.83~0.90 窗口反而对应 LOI-1 ≈ 787 m/s（偏低）。
   ⚠ 这个 0.83~0.90 是上一轮从需求文档里抄来的，来源本身与能量验算矛盾
   （见 `AGENT_HANDOFF/10` §4.5），**很可能就是本轮的根因之一**。
2. 但注意：**本表最省的 84 h / 3147 m/s 也只有 v∞=0.986**，
   而真实的 75.9 h 是 **3180 m/s / v∞=1.087** —— 比真实任务的 3050 贵 ~130 m/s。
   这 130 m/s 是"本模型几何 vs 真实任务"的差距（见 `AGENT_HANDOFF/10` §3.7 层B），
   **是本轮剩下的第二个疑点**：停泊轨道面、RAAN、月球历表、还是我们的地球引力常数，
   哪一处让它贵出 130 m/s？
3. 上表的"到达面"列（两体近似）都在 0.8~10° 量级（不是我们全模型求解器的 0.1° 级），
   因为我们全模型的 B 平面瞄准会主动修正到达面；两体的"面"列只作对照。

## 3. 我们已经试过并排除的方向（请不要重复建议这些）

1. **拉长/加密搜索**：TOF 网格加密（1/400 圈 × 8 个 TOF × 滑行 0~4 h）、
   复核预算 36→120、"在真实状态逐个重解 aim 并试有限弧"（±3 h TOF 扫描，37 个候选）
   → 最省仍是 3288，**方向已扫透**。
2. **放宽验收**：把 v∞ 窗口放宽到 [0.78, 0.92] → 费用反而升到 3293（且影响其它任务）
   → 已回退。到达面 0.1° 与近月点 111±20 km 是需求方定死的，不能动。
3. **入轨省油**：把入轨圆化制导的位置增益从 12/8 s 调到 7.5/6 s →
   剩油反而下降（76.08 t）或不收敛；入轨总耗油 30.2 t 已接近理想（~31 t）。
4. **修正"规划态 vs 实飞态"的滑行差异**（29 m/s 那一项）：已在点火时刻用
   真实状态重解 + TOF 扫描消化掉，不再有额外收益空间。

## 4. 给专家的具体问题

1. **出发能量对不对**：从 184.4×185.2 km、i=32.55° 的停泊轨道，
   在真实发射时刻的地月几何下，**广义兰伯特的最优 TLI Δv 应该是多少**？
   我们的两体下限 3150~3160 m/s（真实任务 3050）是合理的吗？
   若不合理，最可能错在哪（月球历表？月球位置的速度？地球引力常数/半径？
   停泊轨道倾角对出发面的影响？）
2. **为什么最优 TOF 是 96~100 h 而不是 ~76 h**：请判断我们需要检查什么
   （例如：把真实那条 75.9 h 转移用我们的历表复算，看 Δv 与到达几何是多少；
   或用真实 Apollo 11 的 TLI 状态（位置/速度/时刻）反推我们的历表是否一致）。
3. **面约束的代价**：要求"到达轨道面永远含着陆点方向"，
   在真实任务里是靠**发射窗口**实现的（在窗口里挑时刻，让到达面天然含站点）。
   在**固定发射时刻**（我们的 M5 就是真实时刻）下，这个代价的最小值是多少？
   我们实测 +100~140 m/s 是否合理？
4. **上升剖面**：我们的 S-II 交班状态比真实偏低（S-IVB 入轨多烧 ~4~5 t ≈ 120~150 m/s）。
   请判断：真实 Saturn V SA-506 的 S-II 关机状态（高度/速度/航程角）是多少，
   以及"抬高交班高度"能否/应该兑现这 ~150 m/s。
5. **如果以上都正常**：请给出**在你的判断里，本模型这个几何下的 TLI 最小 Δv**，
   以及为了达到它，**出发端需要具备什么条件**（例如停泊轨道面要不要按"到达面含着陆点"重选，
   而不是像现在这样按"停泊轨道面与月球轨道面夹角最小"来选 —— 我们的 M1/M2 就是这样选的）。
