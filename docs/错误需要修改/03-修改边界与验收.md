# 修改边界与验收

## 可以直接修

- 月球点质量引力的符号和间接项。
- 太阳速度缺失。
- 再入主伞 `CdA` 的明显错误量级。
- S-II 干重、S-IVB 干重、S-II/S-IVB 比冲和推力。
- SPS 推力 91200 → 91190 N。
- SPS 比冲 314 → 314.5 s。
- 上升级推力 15570 → 16000 N。

## 不能直接替换

- `CSM.propMass: 24000` 不能直接改成 18410。
- `LM.ascentProp: 3000` 不能直接改成 2353。
- S-IC/S-II/S-IVB 推进剂质量需取得 SA-506 原始称重后再改。
- 发射方位角不能只把 69.4° 改成 72.058°；当前 69.4° 是为了在简化发射模型下凑出 32.521° 倾角。

## 改完最低验收

1. 300 km 圆轨道积分一圈，位置误差应从约 122 km 降到个位数 km 量级。
2. 月球引力项与正确差分加速度的方向点积必须为正。
3. 指令舱主伞低空平衡下降速度约 8～10 m/s，不得出现数百 g。
4. M1 仍能进入 183.2 × 185.9 km、倾角约 32.5° 的停泊轨道。
5. M4 自动着陆仍成功。
6. 恢复真实推进剂后，M5 不得依靠临时补油完成。

## 当前演示兜底

`apollo11/webdata/js/11-demo.js` 中存在自动演示补油和状态同步。它们可以继续保证演示播完，但恢复真实参数时必须把这些兜底记录到日志中，不能把兜底结果当成真实飞行结果。
