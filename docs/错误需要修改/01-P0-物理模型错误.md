# P0：物理模型错误

## 1. 月球引力缺少地心坐标系的间接项，且方向反了

- 文件：`apollo11/webdata/js/03-physics.js`
- 函数：`World.prototype.gravity`
- 当前行：约 286～290

当前代码只加入：

```js
a = V.scaleAdd(a, dm, B.MOON.mu / (dmm * dmm * dmm));
```

其中 `dm = moon.r - spacecraft.r`。这是从飞船指向月球的矢量，因此当前加速度方向是从月球指向飞船，也就是排斥方向。

地心惯性系中的正确月球差分加速度应为：

```text
a_moon = μ_m (r_m - r) / |r_m - r|³ - μ_m r_m / |r_m|³
```

对应修正方向：

```js
var ms = A.moonState(t);
var dm = V.sub(ms.r, r);
var dmm = V.mag(dm);
if (dmm > 1e-3) {
  a = V.scaleAdd(a, dm, -B.MOON.mu / (dmm * dmm * dmm));
  a = V.scaleAdd(a, ms.r, -B.MOON.mu / Math.pow(V.mag(ms.r), 3));
}
```

月球 J2 也使用了同一个 `dm` 方向，修复点质量项后必须同时复核 J2 的矢量方向，不能只改第一行。

### 实测影响

- 300 km 圆轨道、1 秒步长运行一圈：位置误差约 122.5 km。
- 关闭月球相关项后：位置误差降至约 2.0 km。
- 7000 km 处当前月球项与正确差分项的点积为负，确认方向相反。

## 2. 再入伞等效面积单位/量级错误

- 文件：`apollo11/webdata/js/03-physics.js`
- 函数：`World.prototype.effCdA`
- 当前行：约 312～327

当前值：

| 状态 | 当前 `CdA` | 问题 |
|---|---:|---|
| 指令舱再入体 | 40 m² | 可接受的简化量级 |
| 减速伞 | 320 m² | 偏大，但不是首要错误 |
| 主伞 | 2500 m² | 量级错误 |

实测：高度 1 km、速度 100 m/s、质量 5560 kg、`CdA=2500` 时，阻力加速度约 2410 m/s²，约 246 g。

真实阿波罗主伞为三具约 25.4 m 直径伞。即使按 `Cd≈1.5` 的保守上限估算，总 `CdA` 也只有约 2300 m² 的理论上限；实际稳定下降应产生接近 1 g 的阻力平衡，而不是数百 g。

建议先改成可验证的目标，而不是直接塞一个新常数：

- 主伞完全打开后，指令舱在低空的平衡下降速度目标约 8～10 m/s。
- 以 5560 kg、海平面密度 1.225 kg/m³ 反推，主伞总 `CdA` 约 90～140 m²。
- 减速伞应在约 7.3 km 打开，主伞在约 3 km 打开；当前 8 km / 1.5 km 的阈值也需改为真实时序。
- 修改后必须检查溅落速度仍低于当前 15 m/s 的安全判据。

## 3. 太阳位置没有速度

- 文件：`apollo11/webdata/js/02-astro.js`
- 函数：`sunState`
- 当前行：约 191～198

`sunState()` 固定返回 `v = [0,0,0]`。太阳位置公式存在，但速度没有计算。

影响小于月球引力错误，但任何使用太阳速度的轨道计算都会得到零。修复时应由 `sunEcliptic` 对时间做中心差分或解析求导，不要继续返回零向量。
