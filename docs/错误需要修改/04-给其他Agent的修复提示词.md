# 给其他 Agent 的修复提示词

将下面整段原样交给负责修改的 Agent。

---

你现在修复“阿波罗11号模拟器”。先阅读 `AGENT_HANDOFF/` 和 `错误需要修改/`。目标不是让自动演示“尽量跑完”，而是同时满足以下要求：

1. 手动飞行使用真实、正确的实时物理。
2. 五个任务的自动演示变成固定的“实时计算动画回放”：播放过程中不再实时求解制导、不再因帧率或参数产生不同结果。
3. 自动演示轨迹必须对应真实阿波罗11号任务几何，不能为了播完而瞬移飞船。

## 一、必须先修的物理错误

### 1. 月球引力

文件：`apollo11/webdata/js/03-physics.js`

当前 `World.prototype.gravity` 只添加了方向错误的月球直接引力，没有减去月球对地心的引力。地心惯性系中必须使用：

```text
a_moon = μ_m(r_m - r)/|r_m - r|³ - μ_m r_m/|r_m|³
```

月球 J2 使用同一个相对矢量，点质量项改完后必须复核 J2 的方向。修复后，300 km 圆轨道积分一圈的位置误差必须从约 122 km 降到个位数 km 量级。

### 2. 再入伞

`World.prototype.effCdA` 给主伞使用 `CdA=2500 m²`。按当前阻力公式，这会在低空产生约 246 g，属于单位/量级错误。

改成可验证的物理目标：指令舱低空平衡下降速度约 8～10 m/s。以 5560 kg 和海平面空气密度反推主伞总 `CdA`，不要继续使用 2500。减速伞和主伞的打开高度也要改为真实时序。

### 3. 太阳速度

`apollo11/webdata/js/02-astro.js` 的 `sunState()` 不能再返回 `v=[0,0,0]`。用现有太阳位置公式做解析求导或中心差分，生成真实速度。

## 二、自动演示必须改成固定回放

当前 `apollo11/webdata/js/11-demo.js` 的 `Demo.tick()` 在播放时调用实时物理和制导，并且用这些函数直接改状态：

- `demoReturnAssist`
- `demoRndzNormalize`
- `demoRndzCloseOut`
- 返回段和再入段中直接赋值 `c.r`、`c.v` 的兜底逻辑

这些全部禁止出现在最终播放链路中。

正确结构：

1. 新增离线轨迹生成器，例如 `apollo11/webdata/js/12-replay.js`。
2. 使用修复后的物理、真实火箭参数和真实任务时序，离线生成 M1～M5 各一条轨迹。
3. 每条轨迹保存为固定数据，建议使用 JSON 或压缩二进制，包含时间、位置、速度、质量、油门、姿态、当前级和事件。
4. 采样必须确定性：使用固定步长或记录每一步的仿真时间，不允许依赖 `requestAnimationFrame`、墙钟、随机数或未固定的迭代次数。
5. 播放时只按任务时间插值这些固定样本，并用现有渲染器绘制。播放中禁止调用 `World.advance`、制导函数、兰伯特求解、推进剂消耗或任何会改变轨迹的计算。
6. 播放速度可以改变，但只改变样本时间推进速度，不能重新模拟。
7. 连续播放两次，所有样本必须逐值一致；刷新页面、切换中英文、改变窗口大小都不得改变轨迹。

播放器需要支持播放、暂停、停止、重播、速度切换和进度拖动。拖动时直接跳到对应样本时间，不允许从当前状态重新积分。

## 三、真实轨迹约束

自动演示要呈现真实阿波罗11号经过的任务路径，而不是“能完成任务的任意轨道”。

必须对齐以下目标：

- 发射方位角：72.058°，不能继续靠 69.4° 凑倾角。
- 地球停泊轨道：183.2 × 185.9 km，倾角 32.521°。
- TLI：任务时间约 T+9861 s，速度增量约 3.05 km/s，燃烧约 347 s。
- 地月转移：约 75.9 小时到达月球附近。
- LOI-1：约 357.5 s、889 m/s，进入约 111 × 315 km 月球轨道。
- LOI-2：约 17 s、59 m/s，圆化到约 111 × 117 km。
- 着陆点：0.674°N，23.473°E。
- TEI：约 151 s、997 m/s，从真实环月轨道返回地球。
- 溅落目标：13.317°N，169.150°W；总任务时间 195 h 18 min 35 s。

轨迹生成时要输出与这些目标的偏差报告。偏差超出阶段允许范围时，生成器必须失败，不能调用“演示同步”掩盖。

允许的阶段验收起点：

- 停泊轨道高度误差 ≤ 5 km，倾角误差 ≤ 0.2°。
- TLI 速度增量误差 ≤ 50 m/s，燃烧时长误差 ≤ 30 s。
- LOI 后近月点误差 ≤ 20 km，远月点误差 ≤ 40 km。
- 着陆点误差 ≤ 1 km。
- TEI 后必须自然进入地球再入走廊，不得瞬移。
- 溅落位置误差 ≤ 100 km；若暂不能达到，必须在报告中明确失败，不能伪造位置。

## 四、真实参数与禁止事项

优先恢复以下真实参数：

- SPS 推进剂：18410 kg，当前 24000 kg。
- SPS 推力：91190 N。
- SPS 比冲：314.5 s。
- 登月舱上升级推进剂：2353 kg，当前 3000 kg。
- 登月舱上升级推力：16000 N。
- S-II 干重：43000 kg。
- S-IVB 干重：15200 kg。
- S-II 真空推力：约 4.4～5.0 MN，比冲 424 s。
- S-IVB 真空推力：约 1.0 MN，比冲 424 s。
- T+135 s 实现 S-IC 中央发动机关机，推力降为五台时的 80%。

若恢复真实推进剂后现有制导无法完成任务，必须改进制导或离线轨迹求解，绝不能重新增加推进剂、瞬移航天器或在播放时改状态。

手动飞行模式继续实时模拟，不受回放数据驱动。自动演示按钮只启动固定回放。两种模式必须在界面和日志中明确区分。

不要修改 `错误需要修改/` 中的审查记录来掩盖未完成项。完成时新增一份实现报告，列出轨迹偏差、未能达到真实目标的项目和验证命令。
