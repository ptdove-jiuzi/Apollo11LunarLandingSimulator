# 阿波罗11号登月模拟器 · Apollo 11 Mission Simulator

一个独立的桌面小游戏：**从点火起飞，到地月转移、月球轨道对接、动力下降着陆，最后返回地球溅落**。
全部轨道计算基于真实 Apollo 11（土星五号 SA-506）飞行数据与 Meeus 月球历表实现，
并内置了一台**可编程的阿波罗制导计算机（AGC）复刻**——你可以自己写 AGC 汇编程序去驱动 DSKY。

产物：`dist/Apollo11LunarLanding.exe`（单文件，双击即玩，图标已内嵌）

## 一、快速开始

### 直接玩
双击 `dist/Apollo11LunarLanding.exe`。

程序有两条渲染通道，会自动选择：

1. **pywebview / Edge WebView2 原生窗口**（首选）——独立窗口、无地址栏。
2. **浏览器应用窗口兜底**——当 WebView2 运行时缺失或崩溃时自动切换：
   启动一个仅监听 `127.0.0.1` 的本地服务，并用 Edge / Chrome 的
   `--app=` 应用窗口打开（同样没有地址栏与标签页，观感接近原生程序）。

> 本机（开发环境）的 WebView2 运行时会崩溃（`msedgewebview2 has stopped working`），
> 所以程序会自动记录并改用浏览器应用窗口。若你想强制指定：
> ```bash
> set APOLLO11_GUI=browser    # 或 webview
> Apollo11LunarLanding.exe
> ```
> 选择结果保存在 `%USERPROFILE%\Apollo11Simulator\config.json`。
> 启动日志：`%USERPROFILE%\Apollo11Simulator\startup.log`。

### 从源码运行
```bash
python run.py
```
需要一个带 `pywebview` 的 Python 环境（本机 `binaries/python/envs/default` 已具备）。

### 重新打包
```bash
python tools/build_exe.py      # 生成 dist/Apollo11LunarLanding.exe
python tools/make_icon.py      # 重新生成 assets/icon.ico
```

### 自检
```bash
APOLLO11_HEADLESS=1 python run.py     # 检查资源是否完整
```
游戏内「系统自检」页签会跑一遍历表、轨道数学、兰伯特求解、AGC 汇编与执行的断言
（共 11 项，启动时会自动执行一次并把结果写进飞行日志）。

无头浏览器验证（开发用）：
```bash
python -m http.server 8766 --bind 127.0.0.1 --directory apollo11/webdata
msedge.exe --headless=new --dump-dom http://127.0.0.1:8766/index.html
# 页面内的 [#diagout] 节点会写出完整的界面自检报告
```

## 三、五个预设任务

| 编号 | 任务 | 内容 |
|---|---|---|
| 01 | 飞船起飞 | 从 LC-39A 点火，按土星五号真实俯仰程序转弯、分级，进入 183.2 × 185.9 km、倾角 32.521° 的停泊轨道 |
| 02 | 地月轨道转移 | 在停泊轨道上求解 TLI 窗口，执行地月转移注入，3 天后完成月球轨道插入 |
| 03 | 月球对接 | 在环月轨道释放 Eagle，靠轨道力学重新追上并完成刚性对接 |
| 04 | 飞船降落 | 从 111 km 环月轨道实施动力下降，在静海基地安全着陆 |
| 05 | 全流程模拟 | 从点火到溅落的完整 195 小时 18 分 |

### 每个任务都有「自动演示」

任务卡片上【开始任务】**下面**还有一个【自动演示】按钮。点它，模拟器会自己把
整个任务飞一遍，顶上会出现一条横幅显示**当前在做什么**（脉冲红点 + 步骤文字 +
进度 + 当前倍率），随时点【停止演示】就能接管。演示途中可以随意按 `+ / −` 加速
或减速，演示不会中断（关键阶段会自动限幅并写明原因，详见下文「自动演示与时间倍率」）。

演示不是"放录像"，而是**真的在解物理**：它调用和玩家同一套制导律（上升制导、
兰伯特转移求解、VGO 入轨、动力下降闭环制导、交会制导），燃料消耗与轨道根数都是
真实算出来的。几个关键数字（实测）：

| 任务 | 自动演示结果 |
|---|---|
| 01 起飞 | ✅ T+629 s 制导关机，进入 187 × 183 km、倾角 32.6° 停泊轨道 |
| 02 地月转移 | ✅ 自动搜索转移窗口（等 2 圈后点火），TLI Δv = **3.24 km/s**（真实 3.05），3 天后 LOI 自动关机 |
| 03 月球对接 | ✅ 分离 → 拉开安全距离 → 自动交会 → 刚性对接 |
| 04 飞船降落 | ✅ 动力下降 Δv = 2134 m/s，**落点偏差 37 m**，剩余推进剂 ~420 kg |
| 05 全流程 | ⚠️ 起飞 → TLI（**有限推力 305 s / 76.21 t**）→ 抛 S-IVB → **MCC 中途修正** → 接近月球 → **LOI 捕获点火**（SPS 约 1.05 km/s，耗油约 13.5 t）→ 分离登月舱（8.2 t 满油）→ 下降段；**LOI 捕获的稳定性与之后的对准链路仍未跑通**（见下），演示会以**红色横幅明确中止**并写明原因 |

**已知限制（M5 全流程，2026-10-12 复核）**：改成有限推力之后，M5 的**地月段**
已经和真实任务对得上 —— TLI 燃烧 305 s、耗推进剂 76.21 t（真实 347 s / 76 t）、
中途修正 MCC、LOI 捕获点火、分离登月舱都能正常执行，登月舱保持 8.2 t 满油。

仍未跑通的是 **LOI 捕获的稳定性**：捕获点火确实执行了（SPS 消耗约 13.5 t、
Δv 约 1.05 km/s，可在飞行日志里看到完整的燃烧时长/耗油/重力损耗），
但"开环常值姿态 + 只判速度大小"的关机方式控制不了径向速度分量，
捕获出来的轨道近月点时高时低；后面的"等待下降轨道窗口 / DOI"链路随之无法收敛，
演示会以**红色横幅明确中止**并写明原因。要根治需要给捕获点火加闭环矢量控制
（见 `AGENT_HANDOFF/05` 第 6 节第 2 条）。

M4（专门的降落任务）是回归下限：它从构造好的 111 km 环月轨道出发，
**落地、落点偏差 37 m**，多次重跑稳定。

真实任务靠发射窗口 + 多次中途修正把到达精度做到几十公里；本模拟器目前的迭代
制导只做到"开环常值姿态 + 速度关机"，这是接下来最值得继续做的方向
（见 `AGENT_HANDOFF/05-真实轨道学与动力学改造记录.md` 第 6 节）。

其中**登陆段用了一套完整的闭环制导律**（`03-physics.js` 的 `descentGuidance`），
背后有一段挺反直觉的物理：月球 111 km 轨道速度 1.63 km/s，而下降发动机最大加速度
只有 2.93 m/s²，所以下降刚开始时「有效重力」`f = g − vh²/r ≈ 0.04 m/s²` ——
飞行器几乎是**失重**的，下沉率只能被 f 慢慢"喂"出来。制导因此分成
**制动段（P63）→ 接近段 → 终端下降（P66）** 三段，和真实 Apollo 的剖面一致。

另外，停泊轨道的**面**必须包含着陆点/TLI 到达点的月球方向 —— 这靠
`M.raanForInclination()` / `P.orbitOverSite()` 在场景初始化时算出来（真实任务
靠选发射窗口和方位角实现同一件事）。否则兰伯特解出来的 TLI Δv 会是 11.5 km/s
这种荒唐值。

**新功能**
- **3D / 2D 视角模式开关**（视图栏中间那对按钮）：视图按钮决定"看哪儿"
  （地月全景 / 近地 / 近月 / 跟随），模式决定"怎么投影"，两者叠加：
  - **3D**：可旋转的三维视角，左键拖动 = 旋转（yaw/tilt），判断空间关系用它；
  - **2D**：视线方向取**当前轨道面法向** `n = unit(r × v)`，也就是站在轨道水平面
    垂直 90° 的正上方往下看 —— 轨道画出来是正圆/正椭圆，而不是"从北极往下看"
    那种斜投影（倾角 32.5° 的停泊轨道、环月轨道以前全是斜条）。2D 下拖动 = 平移
    （在轨道面内），滚轮缩放，图面 x 轴取近拱点方向（圆轨道退化为升交点方向），
    轨道长轴方向不会随飞船公转打转；参考线也换成轨道面自己的两条主轴。
  - 切模式只换投影，不动观察角度：2D 里看一眼再切回 3D，原来的视角原样恢复。
- **轨道预演**：视图栏右侧「轨道预演」开关。打开后按飞船**当前速度 + 全部引力**
  （地球 μ+J2、月球 μ+J2、太阳第三体，与仿真同一套模型）做 RK4 外推，
  画出接下来约 2.2 圈的轨迹（含月球的引力弯折），每 1/4 段标注时间刻度。
  计算分帧进行不卡顿，点火或沿轨迹走远后自动重算。
- **星球是实心球**：地球/月球先铺一层实色整圆（边缘是硬边界），再在球面内叠
  朝阳面亮部 + 一圈 4.5% 半径的临边暗边，大气辉光收紧成贴着球面的一条细亮环。
  以前"渐变最外圈 = 背景色"，整圈边缘都被化进背景，看着就是一团虚边光斑。

**自动演示与时间倍率**
- 演示进行中改倍率**不会中断演示**：`+ / −` 永远相对**当前真实倍率**走一档
  （以前按的是内部档位索引，而演示每步会把倍率改成自己的值却不更新索引，
  于是演示在 ×50000 滑行时按「+」，倍率反而掉到 ×2 —— 看着就像演示卡住/断了）。
- 玩家按过 `+ / −` 之后，演示**不再每步覆写倍率**，横幅上会显示
  「已接管时间倍率 ×N」。
- **制导关键阶段**（上升、入轨、LOI、动力下降、着陆、月面起飞，步进倍率 4~1000）
  有倍率上限 = 本步推荐值的 2 倍，超了就限幅并在横幅上写明
  「⚠ 制导关键阶段，倍率上限 ×N」；长滑行段则有下限（不低于推荐值），
  免得一次误操作让 73 小时的滑行跑成几十分钟。
- 演示**异常中止会明确报出来**：横幅变红留在屏幕上 20 秒并写明原因
  （飞行器坠毁 / 连续多步卡住），不再"悄悄收尾"让人以为演示自己断了。

**操作要点**
- 顶栏 `+ / −` 调时间倍率（最高 30 万倍），`▶ 继续` 开始/暂停仿真
- 中栏「姿态」按钮选择推力方向；「油门」滑杆控制推力；「自动驾驶」一键执行上升制导
- 分离登月舱之后，用【切换飞行器】在两台飞行器之间切换控制权（按钮上会写切到哪台）
- 底部「轨道计算器」页签里点「计算轨道」求解地月转移，再点「执行 TLI 点火」
- **自动演示会高亮它正在用的那个控件**：横幅上除了步骤文字，还有一行
  「本步操作：点【×××】」，界面上同时用黄色呼吸框圈出对应按钮 ——
  演示"在替你点哪里"一目了然，看完就能自己接手
- 底部「制导手册」页签是本项目最完整的一处说明文档：逐条讲清**每一条制导律**
  （上升 / VGO 入轨 / TLI / MCC / LOI-1 / LOI-2 / 平面机动 / DOI / P63-P64-P66 /
  交会 / 月面起飞 / TEI）的适用阶段、原理、触发方式，以及和真实 Apollo 程序号的
  对应关系；再讲清每个面板控件「什么时候用 / 点了会发生什么 / 典型操作序列」，
  最后给三条照着做就能飞的操作序列。中英双语。
- 底部「AGC 汇编终端」页签里可以写 AGC 汇编、点「汇编并装载到 AGC」，右侧 DSKY 会实时响应
- 左键拖动旋转视角，滚轮缩放

## 四、轨道力学实现

| 模块 | 说明 |
|---|---|
| 参考系 | 地心赤道惯性系（ECI），月球历表在黄道系给出后按黄赤交角 23.4393° 旋转 |
| 月球历表 | Meeus《Astronomical Algorithms》第 47 章周期项级数（经纬距各保留主项），历元常数取自 JD 2440419.0639（1969-07-16 13:32 UT 点火时刻） |
| **月球自转** | **IAU/IAG 月球自转模型**（α₀ / δ₀ / W 周期项保留主项）：自转轴相对黄极倾斜 1.543°、随升交点做 18.6 年进动。旧版拿"轨道法向"当自转轴，极轴误差最大 6.7° |
| 传播 | 通用变量（universal variable）二体传播，椭圆/抛物/双曲统一处理 |
| 转移求解 | 兰伯特问题（Vallado 形式），割线/二分混合求根 |
| **点火** | **有限推力**（真实点火模型）：燃烧中心化 + 常值惯性推力方向 + 速度关机判据，推进剂实时消耗、重力在整段燃烧里持续作用 —— 重力损耗自然出现。规划/估算仍用瞬时脉冲 |
| 数值积分 | RK4，步长按高度自适应（月面 0.02 s ↔ 深空 60 s）；点火末端自动收步长到关机精度 |
| 引力场 | 地球 μ + J2、月球 μ + J2、太阳第三体摄动、地球自转大气阻力 |
| 飞行器 | 土星五号三级 + ESA + LM 下降/上升级 + SM/CM，真实推力/比冲/推进剂质量；S-IC 推力随大气压变化 |

### 已校验的关键数值

|---|---|---|
| 发射时刻月球黄经 | 135.398° | 135.404°（Meeus 完整级数） |

## 五、AGC（阿波罗制导计算机）复刻

参考 `virtualagc/virtualagc`（CPU 模拟器 / DSKY / 工具链）与
`chrislgarry/apollo-11`（AGC 汇编语言与程序结构）**所具备的功能**，
代码全部自行实现，未抄录任何现有源码。

### 已实现

- **CPU**：Block II 指令集，含全部基本指令（TC / CCS / TCF / DAS / LXCH / INCR / ADS / CA / CS /
  INDEX / DXCH / TS / XCH / AD / MASK / DOUBLE / OVSK / COM / DDOUBL / RESUME / RELINT /
  INHINT / EXTEND / RETURN）与扩展指令（READ / WRITE / RAND / WAND / ROR / WOR / RXOR /
  EDRUPT / DV / BZF / MSU / QXCH / AUG / DIM / DCA / DCS / SU / BZMF / MP / SQUARE）
- **数据格式**：15 位反码字（+0 = 0，−0 = 077777），16 位累加器含溢出位，端回进位加法
- **存储器**：固定 36 页 × 1024 字；可擦不切换区 256 字 + 8 个切换页 × 256 字，EBANK 选页
- **中断**：ZRUPT/ARUPT/LRUPT/QRUPT 保存与 RESUME 返回
- **I/O**：256 条通道，READ/WRITE/RAND/WAND/ROR/WOR/RXOR 全部可用
- **DSKY**：PROG / VERB / NOUN / R1 / R2 / R3 + 12 个指示灯 + 完整键盘与键盘中断
- **汇编器**：两遍汇编，符号表、表达式（AGC 约定裸数字为八进制）、伪操作
  （SETLOC / BANK / OCT / DEC / 2DEC / EQUALS / ERASE / CADR / FCADR / ECADR / GENADR / BBCON / COUNT）
- **反汇编器**：单条与区间反汇编
- **下传遥测**：通道写入记录、DSKY 键盘事件、程序告警

### 关于位域的两点说明（诚实声明）

1. 真实 AGC 因字长限制，操作码与 12 位地址存在**位域重叠**（bit10/11 同时承担地址与扩展码）。
   本实现做了**规范化**：操作码占 bits14-10、页内地址占 bits9-0，由 `EXTEND` 切换整张操作码表。
   指令语义、EXTEND 机制、存储器分页、通道 I/O、中断行为均与 Block II 一致。
2. 真实 AGC 用继电器矩阵（通道 010/011）驱动七段管。本实现保留完整的 DSKY 语义，
   但显示接口简化为明确文档化的通道：`021o=PROG  022o=VERB  023o=NOUN  024o=R1
   025o=R2  026o=R3  027o=指示灯`，`013o=键盘(读)`，`015o=状态(读)`；
   另外 `030o=油门指令`、`031o=姿态模式`、`032o=分级` 用于把 AGC 程序接到飞船。

### 自带示例程序（`apollo11/webdata/programs/`）

| 文件 | 内容 |
|---|---|
| `dsky-demo.agc` | 点亮 DSKY，显示 PROG 11 / VERB 16 / NOUN 36，R1 从 0 累加到 99 |
| `attitude-hold.agc` | 通过通道 030o/031o 下发油门与姿态模式驱动飞船，同时计时显示 |
| `lambert.agc` | 用 DV 做定点分数除法、MP 做乘法，结果送 R1/R2（0.125 ÷ 0.5 = 0.25 ✓） |

三个程序均通过实际汇编 + 执行验证。

## 八、已知简化

- 月球轨道倾角相对赤道**不是固定值**：月球位置由 Meeus 级数给出（F 角含交点退行），
  实测发射日相对赤道倾角 28.525°。月球**自转**用 IAU 2000 模型（见第四节）。
- **有限点火的姿态是常值惯性方向 + 速度关机**（开环），燃烧期间没有小姿态修正；
  迭代制导的闭环收敛仍是后续方向（见 `AGENT_HANDOFF/05`）。
- **到达月球的瞄准残差在几千公里量级**，因此 M5 的 LOI 在引力影响球边缘捕获。
- 未实现 AGC 的**解释器（Interpreter）**与真实 AGC 源码的完整装配（36 K 绳存储器镜像需另行获取）。
- 地球大气为分段指数模型，未建模风场与高层大气日变化。
- 指令位域与 DSKY 显示接口做了规范化处理（见上文第四节说明）。
- **自动演示与手动飞行是两套标准**：自动演示必须每次都播完同一条完整链路
  （交会收拢、TEI 修正、返回段各有脚本兜底，日志里明确标注为"演示同步"）；
  手动飞行走真实物理，允许失败，但失败一定是安全的（明确报错、不会打错飞行器）。
  详见 `AGENT_HANDOFF/06-当前状态总览.md`。
