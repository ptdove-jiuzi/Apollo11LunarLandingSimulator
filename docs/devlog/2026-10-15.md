## 第 25 轮：M5 全流程打通（29/29 步，含溅落）—— TEI 根因修复
用户报"M5 演示里飞船没回地球、被弹射回宇宙"。
### 根因（三层，全部实测）
1. **参照系 bug（根因）**：TEI 求解器把**月心系**的 Δv 直接加到**地心**速度上
   （vGoal = pre.v + tHat·dv）→ 目标地心速度 1.638 km/s（当前 0.943）→
   倒退双曲线、远拱 580 万 km —— 就是"弹射回宇宙"。
2. 曾试"目标=返回椭圆地心速度 0.18 km/s"——修反：月心系速度 0.83 < 逃逸
   速度 2.30，飞船根本离不开月球（单元实测 peri −4 363 km）。
3. **正解**：vGoal = msP.v + (vrelP + tHat·dv)（月球公转 + 月心系目标）；
   月心系速度 ≈2.45 > 逃逸速度 ✓，逃逸渐近线把地心速度降到返回椭圆速度 ✓。

## 第 27 轮：修"打不开"——单实例复用了僵尸实例（404）
用户双击 EXE 看到 Edge 的 404 File not found。
### 根因
- 单实例复用逻辑（apollo11/app.py `_running_instance`）只做 **TCP 探活**；
  实测有"进程还活着、但 PyInstaller 的 _MEI 临时目录已被清掉"的**僵尸实例**

1. 复用前必须 **GET 一次 /index.html 且确认 200**（urllib，2.5 s 超时）；
2. 退出时清理自己写的锁文件（`_clear_lock` + atexit + KeyboardInterrupt）。
3. 清理了两个僵尸实例（PID 21244/10776）与旧锁文件。

  51701 ✓ HTTP 200 ✓；新实例已留给用户（PID 21356，勿杀）。

  **真请求一次页面**，不能只 connect；锁文件要 atexit 清。
